# 《风起旧厂街》游戏设计文档

> 一句话定位：2000 年的京海旧厂街，你还是一个卖鱼的高启强——每一步怎么走，由你决定。
> 类型：对话式剧情游戏（Visual Novel / Branching Narrative）｜适龄：16+
> 发布平台（V2.5 四端）：单文件网页 · Windows 免安装 EXE · Android APK · Android PWA
> 配套可玩版本：`01-网页版（写实电影感）/`（网页，双击即玩）· `02-安卓版PWA（写实电影感）/`（PWA）· `05-Android源码工程/`（APK 工程）
> 视觉基调（V2.5）：全平台统一「写实电影感」——照片级场景 + 暗夜玻璃 + 暖琥珀光
> 题材说明：基于电视剧《狂飙》前期故事的同人演绎；角色、地名、事件均为艺术再创作。

---

## 1. 概述

### 1.1 核心目标
玩家以第一人称扮演鱼贩高启强，从 2000 年旧厂街菜市场的一杆秤开始，经历 2006 风起、2015 登顶、2021 潮退四个时代。游戏不提供"正确答案"，只提供取舍：**野心与初心、人脉与风险、巅峰与深渊**，每一次对话选择都在为二十年后写注脚。

### 1.2 设计支柱（V2）
1. **对话即玩法**：全部进程由"读台词 → 做选择"驱动，选择即叙事。
2. **数值因果**：五个属性（资金/声望/人脉/风险/初心）+ 六位人物好感度实时反馈每句话的分量，选项自带效果预览。
3. **经营节奏**：章节之间穿插"风浪回合"经营层，用 4 个回合亲历一个时代，随机风浪事件保证每局不同。
4. **谋略资源**：研读《孙子兵法》习得谋略卡，在六个关键剧情打出隐藏选项——读书从台词变成了真实收益。
5. **命运分支**：3 个章节末风险检定 + 终章 3 条大路 × 属性/印记/好感组合 = 9 种结局 + 13 枚成就。
6. **回响设计**：饺子、《孙子兵法》、"我想吃鱼了"、"风浪越大鱼越贵"等意象在四章间反复呼应，开头即伏笔。

### 1.3 约束条件
- 单文件 HTML，零外部依赖，离线可玩；localStorage 自动存档 + 结局图鉴持久化。
- 暴力情节一律侧写处理（"人没了"），不出现血腥描写；结局传达"法网恢恢 / 回头是岸"的正向主题。

## 2. 核心循环

```
场景（人物台词逐字打印）
   ↓ 点击继续
抉择点（2-4 个选项 + 🃏谋略卡隐藏选项，附效果预览；部分需 人脉/好感/印记 解锁）
   ↓
属性结算（资金/声望/人脉/风险/初心/好感 涨落动画 + 音效）
   ↓
章末检定（风险≥70-75 → 提前败亡结局）
   ↓
🌊 风浪回合（4 回合经营 × 随机风浪事件）→ 下一章过渡卡片
```

周目循环：结局结算（结局名 + 评级 S/A/B/C + 人物命运 + 本次成就）→ 结局图鉴 / 成就 / 谋略集解锁 → 重走一次尝试不同路线。

### 2.1 风浪回合（V2 新增）
每个时代收尾时进入经营层，共 4 回合，每回合从 6 项行动中选一件事：

| 行动 | 效果 |
|---|---|
| 🐟 卖鱼/经营/运转集团 | 赚钱，金额随时代×1 / ×10 / ×1000 |
| 📖 研读《孙子兵法》 | 60% 概率悟得一张未持有的谋略卡 |
| 🤝 结交场面人 | 人脉 +2~4，风险 +1 |
| 🧹 打点关系 | 花钱压风险（-2~-4） |
| 🏠 陪陪家人 | 初心 +2，时代核心人物好感 +3 |
| 🌊 多摆摊/拓张门路 | 小赚或扩张，风险略增 |

每回合 45% 概率降临**随机风浪事件**（三个时代各 6 种：鱼价飞涨、地痞勒索、便衣巡查、对手砸价、丫丫病了、工地出事、审计约谈……），部分事件带二选一抉择。也提供"草草应付直接翻篇"的跳过按钮。

### 2.2 谋略卡（V2 新增）
6 张卡对应《孙子兵法》六计，持有后会在对应剧情自动追加一条 🃏 金色隐藏选项（打出即消耗）：

| 卡 | 剧情切入点 | 效果 |
|---|---|---|
| 瞒天过海 | 徐江白金瀚对峙 | 风险 -8，拖字诀脱身 |
| 借刀杀人 | 徐江末路 | 不依赖老默的第三条路，声望 +10 |
| 反客为主 | 泰叔寿宴 | 不跪的底气：声望 +14 人脉 +8 |
| 金蝉脱壳 | 赵立冬索股 | 表面应承暗中脱壳，风险仅 +4 |
| 以逸待劳 | 莽村危机 | 停工耗到对手内讧 |
| 远交近攻 | 指导组进驻 | 抢先交出赵立冬罪证，风险 -10 |

### 2.3 人物好感度（V2 新增）
安欣 / 高启盛 / 高启兰 / 陈书婷 / 老默 / 黄瑶 六人各有 0-100 好感（HUD 👥 面板可查），由剧情选择与风浪回合累积。好感 ≥70 会在关键剧情解锁隐藏选项（陪启盛坐一整夜、握住安欣的手、向黄瑶和盘托出），安欣好感 ≥75 同样通向"回头是岸"结局。

## 4. 章节结构（约 40 个剧情节点）

| 章节 | 年代 | 关键场面 | 关键抉择 |
|---|---|---|---|
| 一 · 旧厂街 | 2000 | 收"卫生费"、除夕派出所的饺子、徐雷触电、白金瀚赴宴、冻鱼之夜 | 忍/争/记；对安欣的态度；隐瞒或坦白；跪或不跪徐江 |
| 二 · 风起于萍末 | 2006 | 陈书婷递椅、老默出狱、徐江末路、泰叔寿宴、强盛公司挂牌 | 收留或盘剥老默；借刀/送官/放虎；跪认干爹或硬骨头 |
| 三 · 京海之巅 | 2015 | 66 层大厦、赵立冬索股、启盛闯祸、白发安欣雨夜重逢、"吃鱼"暗号 | 给不给保护伞；保弟还是大义灭亲；"不许动他" |
| 四 · 潮水退去 | 2021 | 指导组进驻、赵立冬倒台、黄瑶摊牌、最后一碗饺子 | 烧账本/交出去/送走她；**自首 / 鱼死网破 / 出海跑路** |

终局路由：销毁证据→「灰烬」；初心≥60 且（良知未泯 或 安欣好感≥75）→「回头是岸」；声望≥70→「京海之王·梦醒」；其余→「潮退」。

## 6. 视听风格（V2.5：全平台统一「写实电影感」）

> V2.5 的方向性改动：放弃 V2.4 的四端三套 UI（网页吉卜力奶油色 / 安卓液态玻璃 / 绘画风背景 / 海报风图标），
> 改为**三端共用同一套暗夜电影感视觉**。原因来自明确的产品判断——写实题材（2000 年南方小城、菜市场、公安、夜总会）
> 与卡通化表达存在气质冲突，因此统一收敛到「照片级写实 + 低照度电影光」。

### 6.1 统一视觉语言
- **基底**：近黑 `#07090b` / `#0b0f12` / `#11171b`，三级递进。
- **主色**：暖琥珀 `#e0a04a`（数值、强调、主按钮），辅以冷青 `#3d7681` 作冷暖分离；正文暖白 `#ece5d8`。
- **表面**：暗夜玻璃拟态——半透明深色渐变 + `backdrop-filter: blur(18px) saturate(130%)` + 1px 上亮下暗描边 + 大扩散投影。
  - 性能取舍：毛玻璃只保留在**对白框 / 状态栏 / 底部导航 / 风浪与面板大卡片**这类少量元素上；
    重复出现的选项卡、图鉴格、成就卡已移除 `backdrop-filter`，改用不透明度更高的实心渐变（安卓低端机是主要受益方）。
- **字体**：标题与台词用衬线（宋体系，`Songti SC` / `Noto Serif SC` / `SimSun`）营造年代与文学感；UI 用无衬线。
- **质感层**：`#fog` 全屏 SVG 噪点 `fractalNoise` + `mix-blend-mode: overlay` 做胶片颗粒；
  为此层使用 `transform` 位移动画（而非 `background-position`），走合成层不触发重绘。
- **默认暗色声明**：`<meta name="color-scheme" content="dark">`，避免浏览器/WebView 自作主张反色。

### 6.2 舞台与场景调色
- 背景为**照片级写实图像**，`background-size: cover` + 34s Ken Burns 极缓推移（低特效档关闭）。
- 其上叠 `#scenePhotoTint` 三层调色：上暗（给标题留空间）→ 中透 → 下暗（托住对白），
  加径向暗角，再加一条 115° 的「冷青 → 暖琥珀」分离渐变，形成青橙电影调色。
- `bg-rain` 场景额外叠加 CSS 动画雨丝（由 `MutationObserver` 监听 `#bg` 类名自动挂载 `rainOn`）。

### 6.3 人物呈现（由 Q 版立绘改为虚化前景剪影）
- V2.4 的 14 位 Q 版立绘在写实照片上会直接破坏画面可信度，V2.5 改为：
  立绘 SVG 以 `filter: brightness(0) blur(20px)` + `opacity: .5` 压在画面下缘画外，
  只作为「有人在场」的前景纵深暗示，不暴露任何卡通造型。
- 角色的辨识改由**说话人铭牌**（头像 + 姓名 + 琥珀描边）承担。

### 6.4 图标（三端统一 · 暗底暖金鲤鱼）
- 意象取自主角的起点——鱼摊：近黑深青底 + 胶片颗粒与斜落雨丝，正中一条逆光鲤鱼，
  身体被暖琥珀轮廓光勾亮，晶润湿泽带水珠高光。
- 出图后按尺寸逐个校验可辨识度（32px 下仍能读作鱼），共 10 档 PNG：
  favicon 96、PWA 512/192/180、Android mipmap 48/72/96/144/192、Windows `.ico`（256→16 六档）。

### 6.5 交互：全平台长按拖拽选择
- **长按 170ms 进入拖拽态**：源项缩放 0.97 / 透明度 0.72，触发 14ms 触感反馈（`navigator.vibrate`）。
- 拖动过程中指针下的目标项高亮（琥珀边 + 上浮 5px + 外发光），被锁定的选项不参与高亮。
- 松手即选中：走该项自身的 `onclick`，并抑制随后产生的原生 click（捕获阶段 `stopPropagation`）避免重复触发。
- 首次触发弹出「长按选项可拖动选择」胶囊提示，2.6s 后淡出。
- **不再限于安卓**：V2.4 此交互只存在于 PWA 分支，V2.5 把它并入共用增强层，网页 / 桌面 / 安卓三端一致。
- 边界处理：短按后上下滑动超过 6px 视为滚动，取消长按计时，不误触发拖拽。

### 6.6 共用
- **WebAudio** 实时合成音效：打字滴答、选择确认、风险上升低鸣、章节过场三连音，可一键静音。
- 风险 ≥70 状态栏红色告警（深红胶囊 + 柔光脉冲）。
- **底部悬浮导航**（状态 / 谋略 / 图鉴）：仅在窄屏（≤720px）或触屏设备显示，改善手机拇指可达性；
  桌面端由顶部属性条上的 🃏 / 👥 胶囊承担同等入口。
- **安全区适配**：`--sat` / `--sab` 两个 CSS 变量承载状态栏与导航条高度，默认 0（浏览器下无影响），
  安卓原生层在页面加载完成后注入真实值。

## 8. 构建链

V2.5 引入 `_build/` 作为统一构建层，三端从同一份母版产出：

| 脚本 | 作用 |
|---|---|
| `_build/theme.css` | 全平台唯一样式来源 |
| `_build/prep_assets.py` | 生成两套背景 WebP（横版 1440w / 竖版 880w）+ 图标 10 档 |
| `_build/build.py` | 以原网页版为基底做「样式 + 背景 + 交互增强」替换，产出网页版 / PWA / APK 资源三份 |
| `_build/build_apk.py` | 免 Gradle 出包：aapt2 → javac → d8 → zipalign → apksigner |
| `_build/build_desktop.py` | PyInstaller onefile 出 EXE |
| `_build/shots_pw.js` · `test_drag.js` · `test_qa.js` | 截图 / 交互回归 / 剧情自检 |

**关键工程约束（踩过的坑）**
- `aapt2` 与 `apksigner` **不支持非 ASCII 路径**——连仓库目录名里的中文都会让 `aapt2 compile` 报
  `failed to open directory`。构建脚本因此先把工程暂存到纯英文临时目录，产物再拷回。
- `d8.bat` / `apksigner.bat` 依赖 `JAVA_HOME`，需在子进程环境里显式注入。
- 边距陷阱：`#title>*{position:relative}` 与 `#titleArt{position:absolute}` 同优先级，
  后者先定义会被前者覆盖，导致主视觉塌成 0 高度而整屏发黑。改为逐个子元素声明。
- `os.replace` / `shutil.move` 在文件被预览程序占用时会失败，构建脚本一律用「复制后再归位」。
