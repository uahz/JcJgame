## 本轮针对反馈的问题，逐条处理结果

| # | 反馈的问题 | 状态 | 根因与修法 |
|---|---|---|---|
| 1 | 点「图鉴」显示不完全 / 整页空白 | ✅ 已修 | **根因**：`onclick=showGallery` 直传，浏览器把 click 的 **事件对象**当成了 `tab` 参数，渲染函数拿到脏值直接塌掉。**修法**：改 `()=>showGallery("end")`，并在 `showGallery` 入口加 `tab` 白名单收敛（非 end/ach/card 一律回落 `"end"`） |
| 2 | 状态栏没显示 / 沉浸没做进去 | ✅ 已修 | **根因**：主题用了 `Theme.NoTitleBar.**Fullscreen**` 把状态栏整个藏掉；且安全区注入有**单位错误**（`getSystemWindowInsetTop()` 返回物理像素，被当 CSS px 用，顶栏被撑高 dpr 倍）。**修法**：改用 `Theme.Material.NoActionBar`，保留状态栏 + 透明背景 + 内容铺到栏下，显式关掉 Android 10+ 的 `setStatusBarContrastEnforced`；安全区按 density 换算后再注入 |
| 3 | 顶部一条大黑边 | ✅ 已修 | 同上（对比度蒙版 + 安全区单位错误的复合结果）；另补 `html[data-theme="day"] #hud` 亮色渐变，日间模式下顶栏不再是深色横带 |
| 4 | 返回键直接退出到桌面 | ✅ 已修 | **根因**：顶层 `let st=null` 不挂在 `window` 上，而底栏与返回键都按 `window.st` 判断"是否在局中"——判断恒为 false，于是"在局内"的分支永远走不到。**修法**：`Object.defineProperty(window,"st",{get,set})` 桥接到同一个变量；返回键三级：先关界面（图鉴 / 面板 / 结局）→ 风浪回合与时代过场属强流程不退 → 无处可退时提示「再按一次退出」，两秒内再按才真正退出 |
| 5 | 图鉴里按返回回到了桌面（应回主界面） | ✅ 已修 | 同上的 `window.st` 桥接问题，以及图鉴没有"从哪来回哪去"的概念。**修法**：新增 `closeGallery()` + `galFrom` 记录来源（标题页 / 结局页 / 局内），关掉就回来源处 |
| 6 | 底栏「状态 / 谋略」点了没反应 | ✅ 已修 | 同 `window.st` 根因（`if(window.st)` 不成立 → 静默 return，看起来像按钮坏了）。桥接后正常打开面板；不在局中时改为明确 toast「开局后才能看人物状态 / 谋略」 |
| 7 | 仿苹果液态玻璃没有 | ✅ 已修 | **根因**：低特效档判定过宽——`navigator.hardwareConcurrency <= 4` 把大量中端机误判成弱机，`body.lfx` 一上，所有毛玻璃/折射被整体降级成实心渐变。**修法**：收紧为 `c<=2 || (c<=4 && m<=2)`（内存也参与判定），并在 HUD 新增 **✨ 手动特效开关**，选择持久化到 `localStorage` |
| 8 | 底栏动效没设计好 | ✅ 已修 | 拖动时只有 hot 项被反白，原选中项仍是「深底 + 深字」看不清。**修法**：`#nav.sliding .navbtn.active:not(.hot){color:var(--ink2);font-weight:400}` 让原选中项在滑动期间让位；`#navScrim` 去掉多余 `blur(2px)` 只留暗角，蒙版不再把整页糊掉 |
| 9 | 当前选择要有高亮 + 蒙版提示 | ✅ 已有（v2.6 起） | 选中项背后一枚会滑动的液态玻璃透镜；按住拖动时整页压蒙版 + 手指下的项实时反白 |
| 10 | 长按拖拽要像苹果液态玻璃 | ✅ 已有（v2.6 起） | 长按 170ms 进入拖拽态，跟随指针的玻璃透镜（真折射 + 镜面高光），目标项实时高亮，松手即选中 |

## 待办 / 未完成

1. **APK 签名换了**（重要）。旧包（v2.2–v2.6）用的是原开发机上的 debug 证书，那份 keystore 不在发布包里，
   沙箱重建无法复用 → v2.7 是用新生成的 debug 证书签的，**装过旧版的手机会拒绝覆盖安装，必须先卸载**。
   新证书已随包提供：`05-Android源码工程/keystore/fengqi-debug.keystore`（口令 `android`，别名 `androiddebugkey`）。
   以后一直用它就能保持覆盖安装；要上架请换正式签名，且换一次之后别再换。
2. **未在真机 / 模拟器上实测**。所有安卓截图与断言都是「APK 真正的 assets + 真机视口渲染 + 按原生方式注入安全区」，
   没有跑过真实设备。尤其建议实测：**沉浸式状态栏**（`setStatusBarContrastEnforced` 的行为各厂商 ROM 有差异）
   与**返回键**。
3. **液态玻璃的性能未在低端机实测**。折射是 GPU 开销，目前只对少量元素启用；
   若真机掉帧，点 HUD 的 ✨ 即可整体降级（或调 CSS 里的 `--lg-blur`）。
4. 早/晚模式目前是手动切换 + 记忆，**没有跟随系统深色模式**；要跟随的话，读
   `matchMedia('(prefers-color-scheme: dark)')` 作为默认值即可。
5. 透镜贴图在页面里内嵌了两份（lgLens / lgLensStrong 各一份），可合并为一份引用省 ~10KB。

## 怎么继续（开发环境）

> ⚠️ 本仓库不含页码级构建脚本 `_build/`（属开发机工具链，且其产物停留在 v2.5，
> 直接重跑会把 v2.6/v2.7 的补丁覆盖掉）。仓库内可直接使用的构建入口是
> `05-Android源码工程/build_apk.bat`。以下命令仅作开发机参考：

```bash
# 改样式 -> 重新生成三端页面
python _build/build.py

# 改了安卓原生代码 -> 重新出包（需 JDK 17 + Android SDK build-tools 34）
python _build/build_apk.py

# 桌面版
python _build/build_desktop.py

# 验证
node _build/test_v26.js      # 功能断言
node _build/test_qa.js 600   # 剧情自检
node _build/test_drag.js     # 拖拽选择断言

# 打包
python _build/package.py
```

> 注意：`_build/base/fengqi-jiuchangjie.html` 是承载全部游戏逻辑的**替换母版**（v2.4 原版），
> 不要直接修改；`build.py` 只在它上面做替换生成三端页面，手改生成物会被下次构建覆盖。
