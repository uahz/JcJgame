【v2.7 更新 · 逐条修掉你反馈的问题】
  · 图鉴点开显示不完全 / 整页空白 —— 根因是 onclick 直传把浏览器的 click
    事件对象当成了标签参数，已改为显式传值 + 白名单收敛。
  · 顶部状态栏不显示 / 一条大黑边 —— 根因是安全区注入的单位错误（系统给的是
    物理像素，被当成 CSS px 用，顶栏被撑高 dpr 倍）；另有 Android 10+ 给透明
    状态栏垫的对比度蒙版没关。两处都已修好，现在是真正的沉浸式状态栏。
  · 返回键一按就退出到桌面、在图鉴里按返回也回不去主界面 —— 根因是顶层
    变量没挂在 window 上，外壳判断"是否在局中"永远是 false。已桥接修复，
    返回键现在分级：先关当前界面（图鉴 / 面板 / 结局）→ 强流程不退 →
    无处可退时提示「再按一次退出」。
  · 底栏「状态 / 谋略」点了没反应 —— 同一个根因，已修；不在局中会明确提示
    「开局后才能看人物状态 / 谋略」，不再装死。
  · 仿苹果液态玻璃没了 —— 根因是低特效档判定过宽，把大量中端机误判成弱机、
    把玻璃整体降级成实心色块。判定已收紧，另外 HUD 右上新增 ✨ 键，
    可随时手动切换「特效 / 流畅」，选择会被记住。
  · 底栏动效 —— 选中项背后是会滑动的液态玻璃透镜，按住可横滑切换；
    拖动时手指下的项实时反白，原选中项让位成浅色，整页压一层暗角蒙版。
  · 日间模式下顶栏仍是深色横带 —— 已补亮色顶栏。
  ★ 重要：v2.7 的 APK 换了新的签名证书（旧证书只存在于原开发机，无法复用），
    所以**装过旧版的手机会提示无法覆盖安装，请先卸载旧版再装 v2.7**。
    新证书随包提供：05-Android源码工程/keystore/，以后一直用它即可覆盖安装。

【v2.6 更新】
  · 仿苹果液态玻璃：面板/对白框/底栏/主按钮改用**真折射**（径向透镜法线贴图 +
    SVG 位移），玻璃中心不偏折、越靠边偏折越强，加镜面边缘高光与跟随指针的反光斑。
  · 全新底栏交互：选中项背后是一枚会滑动的液态玻璃透镜；**按住底栏横滑即可切换**
    状态 / 谋略 / 图鉴，滑动时整页压一层蒙版提示「正在切换界面」，全程有触感反馈。
  · 长按拖拽升级：拖动时有一枚跟随指针的**玻璃透镜**，被拖过的目标项实时高亮。
  · 新增日间 / 夜间双模式：HUD 一键切换并记住选择。日间不是反色，而是亮玻璃 + 深字，
    并降低照片的压暗与暗角；状态栏图标明暗会跟随主题自动切换。
  · 修复沉浸式状态栏：先前顶部有一条大黑边、状态栏图标也不显示。改为保留状态栏 +
    透明背景 + 内容铺到栏下，并关掉 Android 10+ 默认给透明状态栏垫的对比度蒙版。
  · 修复安全区单位错误：系统返回的是物理像素，之前被当成 CSS px 用，导致顶栏被撑高
    dpr 倍（Pixel 7 上 71px，实际应为 32px）。现已按 density 换算。
  · 修复返回键直接退到桌面：现在先关界面（图鉴 / 面板 / 结局），
    风浪回合与时代过场属强流程不关也不退；无处可退时提示「再按一次退出」。
  · 修复图鉴显示不完全：覆盖层用 flex 居中 + 可滚动时会把顶部标题与标签栏顶出可视区，
    已改为「首元素 margin-top:auto / 末元素 margin-bottom:auto」的正确写法。

【v2.5 更新】
  · 全新写实电影感画风：7 个场景全部换成照片级写实背景（低照度、
    暖琥珀实用光 × 冷青阴影、浅景深、胶片颗粒、湿面反光），

  · 全平台长按拖拽选择：按住选项约 0.17 秒进入拖拽态，拖动时目标项
    高亮并伴随触感反馈，松手即选中（Apple 式手感）。三端通用。
  · 安卓性能优化：页面体积从 1020 KB 降到 121 KB（背景改为独立 WebP
    文件按需加载），关闭系统强制暗色（保住照片原调色），开启预栅格化，
    移除重复元素的毛玻璃，弱机自动进入低特效档。APK 从 1065 KB 降到 813 KB。
  · 新增底部悬浮导航（手机拇指可达：状态 / 谋略 / 图鉴）。
  · 全新图标：暗底暖金鲤鱼（尺寸小到 32px 仍清晰）。
  · 修复桌面版存档失效：原先以 about:blank 加载，localStorage 不可用，
    现改为本地 HTTP 服务承载，存档 / 图鉴 / 成就可正常跨次保留。

【三端玩法一致，视觉统一】
  全平台共用同一套写实电影感视觉：真实照片背景 + 暗夜玻璃面板 + 暖琥珀光。
  差异只在适配：桌面为横版构图（1440w 背景），手机为竖版构图（880w 背景）。

【核心玩法】
  · 对话驱动：40+ 剧情节点，四个时代（2000 旧厂街 → 2006 风起 → 2015 登顶 → 2021 潮退）
  · 五维属性：资金 / 声望 / 人脉 / 风险 / 初心，每个选项自带数值效果预览
  · 风浪回合：章节之间的经营层，每时代 4 回合 + 18 种随机风浪事件
  · 谋略卡：研读《孙子兵法》习得 6 张卡，可在 6 个关键剧情打出隐藏选项
  · 人物好感：安欣 / 启盛 / 启兰 / 大嫂 / 老默 / 黄瑶 六人好感度，≥70 解锁专属选项
  · 成就系统：13 枚成就；9 种结局；S/A/B/C 评级；三页图鉴（结局 / 成就 / 谋略）
  · 演出：7 个写实场景背景，随地点与对话对象切换淡入；人物以虚化前景剪影暗示在场
  · 演出：液态玻璃面板（真折射）随场景透射背景，跟随指针产生反光斑

【操作】
  点击对话框（或按空格 / 回车）推进剧情；点击选项做出抉择
  长按选项约 0.17 秒进入拖拽选择：出现跟随手指的玻璃透镜、目标项高亮、松手即选中
  底栏：轻点切换，或**按住后左右滑动**连续切换 状态 / 谋略 / 图鉴（滑动时整页压蒙版）
  HUD 右侧「🌙 夜间 / ☀️ 日间」按钮可切换配色，选择会记住
  HUD 右侧「✨」按钮可切换特效 / 流畅（弱机自动降级，也可手动开关，选择会记住）
  安卓返回键：先关当前界面，无处可关时提示「再按一次退出」
  风险 ≥70 时状态栏红色告警——章末检定不过，故事提前终结

【存档】
  自动存档（安卓 / 网页存本地存储，桌面版存 %APPDATA%\FengqiJiuchangjie）
  结局图鉴、成就、谋略集进度均持久化，支持多周目收集

【从源码构建】
  源码仓库：https://github.com/uahz/JcJgame （含全部源码、文档与截图）
  Android APK：运行 05-Android源码工程\build_apk.bat
               （需 JDK 17 + Android SDK build-tools 34 / platform 34，Windows）
               构建链 aapt2 → javac → jar/d8 → 组装 → zipalign → apksigner，
               产物写入 03-Android安装包/。
  签名：05-Android源码工程/keystore/fengqi-debug.keystore（口令 android，别名
        androiddebugkey）；以后出包都用它，才能覆盖安装旧版。
  说明：aapt2 / apksigner 不支持非 ASCII 路径，脚本会自动把工程暂存到纯英文
        临时目录后再打包。
